# 📓 Bitácoras

![PDF](https://img.shields.io/badge/PDF-EC1C24?style=for-the-badge&logo=adobeacrobatreader&logoColor=white)
![APA 7](https://img.shields.io/badge/Normas-APA%207-2EA44F?style=for-the-badge)

Registro del avance del proyecto M.A.V.I. a lo largo del semestre. Cada periodo cuenta con una bitácora de **planeación**, que define las actividades a realizar y sus responsables, y una de **planeación y ejecución**, que contrasta lo planeado con lo realizado. En conjunto, garantizan la trazabilidad del ciclo de desarrollo.
