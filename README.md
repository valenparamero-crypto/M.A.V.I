# 🤖 M.A.V.I. — Módulo Autónomo de Visión Inteligente

M.A.V.I. es un Vehículo Guiado Automáticamente (AGV) se desarrollará como proyecto semestral integrador de Ingeniería Mecatrónica en la Universidad Tecnológica de Pereira. El sistema sera capaz de transportar cargas de hasta 1 kg entre estaciones predefinidas de carga y descarga, navegando de forma autónoma en una pista compartida mediante visión artificial y reconocimiento de códigos QR.
